1. APPLICATION OVERVIEW
-----------------------
The Fitness App is a FastAPI-based backend with PostgreSQL, JWT authentication, Razorpay payments, Cloudinary media storage, and WebSocket notifications. It has separate API routes for users (/api/v1) and admins (/api/admin).

Entry Point: app/main.py - FastAPI with Uvicorn on 0.0.0.0:8000
Authentication: JWT access tokens (60min) + refresh tokens (7days) with database-backed revocation
Database: PostgreSQL via SQLAlchemy ORM with some raw SQL queries
External Services: Razorpay (payments), Cloudinary (media), EmailJS (email OTP)
Real-time: WebSocket for admin notifications (/ws/admin/notifications)

Key Routes:
User: register, login, profile, activities (daily/monthly/yearly), meals, workouts, subscriptions
Admin: user management, content management (workouts/meals/BMI), subscription plans, notifications, dashboard

Data Models: User, Admin, DailyActivity, UserMonthlyActivity, UserYearlyActivity, RefreshToken, Workout, Meal, BMIClassification, Subscription, Payment, PaymentHistory, Plan, UserActivityLog
